# Run 19 — CY-018 (guide Part II §39) — save/load wrapper-metadata contract

**Priority:** P2  **Area:** `annoy/_annoy/annoylib.pyx.in` (`Index.save`/`Index.load`)  **Gate tier:** ring

## Finding
Native `save`/`load` persist the NATIVE index only (dimension `f`, metric, item
vectors, built trees). Structural metadata IS validated on load — an `f`
(node-size) or metric (hash) mismatch raises. But wrapper query params
(`n_neighbors`) and the build `seed` are not part of the `.ann` format, so after
load they silently retain the loading instance's values (verified: saved
`n_neighbors=9, seed=123` -> loaded reports `3, 999`). The docstrings did not
state this contract, and `load` mis-declared the mismatch exception as
`RuntimeError` when the actual type is `IOError`/`OSError`.

CY-014 (state labeled JSON-portable too broadly) was checked and does NOT
reproduce: `get_state` carries no `format`/`portable`/`json` label, `index_data`
is honestly `bytes`, and nothing claims JSON portability — no fix needed.

## Fix (honest, explicit persistence contract)
No format change (native `.ann` interop is deliberate). Corrected and completed
the `save`/`load` docstrings: `save` now states it persists the native index only
(not `n_neighbors`/`seed`); `load` documents that `f`+metric are validated (raising
`IOError`/`OSError`, not `RuntimeError`) and that wrapper query params remain at
the loading instance's config — use `pickle`/`get_state`/`set_state` for full
wrapper-state round-trip. Diff: `out/annoylib.pyx.in.run19.diff`.

## Verification
`tests/test_save_load_contract.py` (5) locks the contract: load rejects `f`
mismatch and metric mismatch with `IOError`; the backing mirrors exactly
(n_items, every item vector, and `get_nns_by_item`); wrapper `n_neighbors`/`seed`
stay at the loader's config (documented non-mirror); and the `load` docstring
documents the contract with the accurate exception type. Ring green: annoy/_annoy
392, annoy serialize 3, euclidean 12, kiss 123.

## Note
`save`/`load` use a raw `char*` error with a correct manual `free()` (unlike the
R14/CY-005 site, they do free). Migrating them to `ScopedError` for consistency
remains the low-risk follow-up noted in R14. Build note: docstring-only edits to
`annoylib.pyx.in` still require the full heavy annoy recompile (~5 min) — allow
the full timeout so linking completes.
