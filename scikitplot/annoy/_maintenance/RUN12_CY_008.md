# Run 12 — CY-008 (guide Part II §31) — out-of-range reads reached unchecked native access

**Priority:** P0/P1  **Area:** `annoy/_annoy/annoylib.pyx.in` (Cython `Index`)  **Gate tier:** ring
**Note:** first Part II (Cython layer) finding.

## Finding (runtime-verified)
`get_item`, `get_nns_by_item`, and `get_distance` validated only *negative* ids
and *dtype capacity* (overflow), not the upper bound. An id in
`[n_items, dtype_max]` reached the native read and returned garbage instead of
raising — a memory-safety / silent-wrong-output defect. `get_nns_by_item`'s
docstring even claimed it raised for `item >= n_items`, but the code did not; only
`__getitem__` actually checked the upper bound (via `get_n_items_w()`).

Reproduced: with 10 items, `get_item(10)` and `get_item(100)` returned lists;
`get_distance(0, 50)` returned a number — all without raising.

## Root cause
No shared existence validator: each item-taking method open-coded a partial
check, and the `>= n_items` bound was missing from all but `__getitem__`.

## Fix (one validator — the exit gate)
Added a single `cdef void _check_item_in_range(self, item) except *` on the
`Index` class that rejects, before any native access: negative ids, over-capacity
ids (via the existing `_validate_item_id`), a not-constructed index, and ids
`>= get_n_items_w()`. `get_item`, `get_nns_by_item`, and `get_distance` (both ids)
now route through it. Diff: `out/annoylib.pyx.in.run12.diff` (+~20 lines net).

Holes are preserved: annoy permits gaps (`n_items == max_id + 1`), so an id in
`[0, n_items)` that was never populated is a valid hole (native returns zeros) and
is NOT rejected — only `id >= n_items` is.

## Verification
`tests/test_item_bounds.py` (12 tests): out-of-range `get_item`/`get_nns_by_item`/
`get_distance` raise `IndexError`; negatives still raise; valid ids still return
correct data; and a hole inside `[0, n_items)` does not raise while `id == n_items`
does. Ring green: annoy/_annoy 333, annoy euclidean 12, **holes 5** (gap handling
intact), types 8, save-atomicity 3, kiss 123.
