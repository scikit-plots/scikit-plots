# Run 18 — CY-017 (guide Part II §27.2) — Cython exception decls don't mirror the no-throw core

**Priority:** P1/P2  **Area:** `annoy/_annoy/annoylib.pxd.in` (`Kiss64Random` extern)  **Gate tier:** ring

## Finding (declarative correctness / error propagation)
The core is the strict no-throw model: `AnnoyIndexInterfaceBase` methods are
`noexcept` and report failure through `char** error` out-params (R7/OBS-001). But
the `Kiss64Random` extern block declared its operational methods
(`reset`, `reset_default`, `set_seed`, `kiss`, `flip`, `index`) as `except +`,
which fails to mirror the no-throw core — it asserts a C++-exception boundary that
does not exist and adds dead exception-translation. The guide (§27.2): pick one
model and "do not leave the choice implicit per method."

## Root cause
The RNG methods in `kissrandom.h` are `inline` pure arithmetic (bit shifts,
`kiss() % n` with an `n==0` guard) that neither allocate nor throw, yet were
annotated as if they could throw C++ exceptions.

## Fix (strict no-throw core)
Changed the six `Kiss64Random` operational methods from `except +` to `noexcept`
so the declarations mirror the actual no-throw contract, with an explicit policy
comment. Constructors (`Kiss64Random`, and `AnnoyIndex`/`HammingWrapper`) keep
`except +` because they allocate via `new` and may throw `std::bad_alloc` —
making the per-method choice explicit and correct, not implicit. Diff:
`out/annoylib.pxd.in.run18.diff`. The Cython `Index` never calls these RNG methods
directly (the C++ template uses them internally), so this is a declarative fix.

## Verification
Heavy annoy rebuild compiles clean (no `noexcept`/exception warnings). RNG path
confirmed intact through the index: same seed reproducible, different seeds
differ (tree-construction RNG genuinely active on 20-D data with 1 tree).
`tests/test_rng_noexcept_decls.py` (3): reproducibility + RNG-active behavioral
guards, plus a structural guard that the pxd RNG operational methods are declared
`noexcept` and not `except +` (skips if the build input isn't installed). Ring
green: annoy/_annoy 387, euclidean 12, holes 5, kiss 123.
