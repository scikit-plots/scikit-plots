# Run 14 — CY-005 (guide Part II §28) — native error-string leak in on-disk path

**Priority:** P1  **Area:** `annoy/_annoy/annoylib.pyx.in` (`Index.on_disk_build`)  **Gate tier:** ring

## Finding (source-confirmed)
Native failing calls return a heap-allocated (`strdup`) error string via a
`char**` out-parameter; the caller owns it and must `free()` it. Every site did
— `build`, `add_item`, `unbuild`, and the internal on-disk build path all free
before raising — **except the public `on_disk_build`**, which decoded the string
into an `IOError` and raised with a raw `char* err`, leaking one allocation on
every on-disk build failure.

Reproduced: 40 000 failing `on_disk_build` calls leaked measurably before the fix.

## Fix (guide decision — centralize native error ownership)
A `ScopedError` RAII class already existed (frees its `char* err` in
`__dealloc__`) with a documented usage pattern, but `on_disk_build` used a raw
pointer. Routed `on_disk_build` through `ScopedError` (`&err.err` in the `nogil`
call; decode `err.err` on failure), so the free happens automatically on every
exit — including the raise. This both fixes the leak and removes the duplicated,
easy-to-forget manual-`free` at this site. Diff: `out/annoylib.pyx.in.run14.diff`.

## Verification
- RSS proxy (native stderr silenced): **0 KB** growth over 40 000 failing
  `on_disk_build` calls (pre-fix leaked ~1.6 MB of `strdup` strings).
- `tests/test_on_disk_error_ownership.py` (3): failure raises `IOError`; success
  still builds; and 500 repeated failures leave a fresh index fully usable
  (error path stable under repetition). Leak-freedom is structurally guaranteed
  by `ScopedError` RAII, so the permanent test locks the observable contract
  rather than a flaky RSS threshold.
- Ring green: annoy/_annoy 358, euclidean 12, holes 5, kiss 123.

## Note
The remaining raw-`char*` sites (`build`, `add_item`, `unbuild`) already free
correctly, so they were left untouched (minimal impact). Migrating them to
`ScopedError` too is a low-risk consistency follow-up, not a defect.
