# Maintenance model

Separate five truths: static maintenance health, native dependency runtime behavior, harness-only compatibility diagnostics, complete-package integration, and release evidence. A compatibility shim used only to explore deeper behavior is not a runtime fix.

Fail closed on public parameters that are accepted but ignored. Plot creation is not sufficient evidence: verify computed values, artist semantics, dependency compatibility, and estimator/weight/hue inputs with adversarial probes.
