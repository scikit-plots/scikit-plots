# `_cli` maintenance plane

This directory is maintainer tooling and evidence for `scikitplot._cli`. It is
not imported by runtime code. `check_trackers.py` is the fail-closed structural
contract gate; `review_subsystem.py` presents the review lanes and open findings.

Historical narratives are not authority. Current runtime bytes, `MAINTENANCE.json`,
`STATE.json`, and current evidence are authority.
