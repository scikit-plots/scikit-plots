# Observed dependencies

[FAMILY.md](FAMILY.md) explains the six typed relationships.
[DEPENDENCY_GRAPH.json](DEPENDENCY_GRAPH.json) records actual imports/header
references with file and line evidence, regenerated by the tracker command.

```sh
python -B maintenances/cexternals/_annoy/_maintenance/dependency_map.py
```

This command is read-only. It checks only _annoy-related edges when scanning the
wider package, so a newly added direct consumer is visible without onboarding
unrelated packages. It does not write a stray `dependency_graph.json` at the
repository root. For deliberate changes, review the graph and run
`check_trackers.py --update` from this maintenance directory's executable path.
