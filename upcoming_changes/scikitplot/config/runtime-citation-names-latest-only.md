# scikitplot.__bibtex__ cites every version, never the installed build

## Summary

`scikitplot.config._citation` (generated at build time from
`scikitplot/config/_citation.py.in`) returns the first `@software` entry of
`CITATION.bib`, the all-versions entry. The installed package knows its exact
build (`scikitplot.version.full_version`, `git_revision`), but no function
returns a citation for it.

## Why it matters

A notebook that wants to record exactly what it ran can only cite "latest" at
run time; `CITATION.bib`'s version entry names the commit the file was
generated from, which can differ from the installed build.

## Current evidence

- `_get_bibtex()` splits `CITATION.bib` on `@software` and keeps `[1:][0]`.
- `scikitplot/version.py` (generated by `gitversion.py`) holds
  `full_version` and `git_revision`.

## Root cause / current understanding

The runtime module predates version entries; it was written for one entry.

## Expected behavior

A function (for example `scikitplot.config.citation(which="build")`) renders
the version entry for the installed build from `scikitplot.version`, with the
same fields as `tools/citation/citation_ref.py`, without reading the network.

## Affected paths and ownership

`scikitplot/config/_citation.py.in`, `scikitplot/config/__init__.py`,
`tools/citation/` (one source for the entry's fields).

## Constraints and non-goals

`__bibtex__` keeps returning the all-versions entry (an existing contract).

## Edge cases to cover

A build without git (`git_revision == ""`); a release without a Zenodo DOI;
an sdist build.

## Proposed direction

Generate the field values into `_citation.py` at build time from the same
`PROJECT`/`VERSION_DOIS` data the tool uses, and format the entry at run time.

## Verification / acceptance criteria

The entry's `version` and `url` equal `scikitplot.version.version` and the
tree of `git_revision`; a test builds it for a dev and a release version.

## Documentation impact

`docs/source/project/citing.rst`.

Required (`scikitplot.config`, enhancement).
