# cache_zenodo_svg.py rewrites citing.rst with matplotlib's DOIs

## Summary

`tools/citation/cache_zenodo_svg.py` is a copy of matplotlib's script. Its
`data` table holds matplotlib's versions (`v3.9.2` ... `v1.4.0`) and Zenodo
record numbers, it caches under `~/.cache/matplotlib`, and it reads and
rewrites `doc/project/citing.rst` (this repository uses `docs/source/`).

## Why it matters

Run as is, it fails (no `doc/`); pointed at `docs/source`, it would replace
the scikit-plots DOIs in `docs/source/project/citing.rst` between
`.. START OF AUTOGENERATED` and `.. END OF AUTOGENERATED` with matplotlib's.

## Current evidence

- `tools/citation/cache_zenodo_svg.py`: `data = {"v3.9.2": "13308876", ...}`,
  `doc_dir = Path(__file__).parent.parent.absolute() / "doc"`,
  `Path(cache_dir, "matplotlib")`.
- `docs/source/project/citing.rst` lists the scikit-plots records
  (`13367000`, `13367095`, `13367001`, `591428`, `1245853`).

## Root cause / current understanding

Imported from matplotlib without adaptation; nothing runs it (no make target,
no workflow), so it never failed.

## Expected behavior

One registry of scikit-plots version DOIs feeds both `citing.rst` and the
citation files: `VERSION_DOIS` in `tools/citation/citation_ref.py` today.

## Affected paths and ownership

`tools/citation/cache_zenodo_svg.py`, `docs/source/project/citing.rst`,
`tools/citation/citation_ref.py` (`VERSION_DOIS`).

## Constraints and non-goals

Network access only in an explicit command; the badge images stay optional.

## Edge cases to cover

A version listed twice; a record number that is not numeric; the markers
missing from `citing.rst`.

## Proposed direction

Either delete the script, or let `citation_ref.py` render the
`citing.rst` DOI block from `VERSION_DOIS` (offline, no badge download).

## Verification / acceptance criteria

`citing.rst`'s DOI block and `VERSION_DOIS` agree, checked by
`citation_ref.py check`.

## Documentation impact

`docs/source/project/citing.rst`.

## Release-note promotion

Not required (maintenance tooling).
