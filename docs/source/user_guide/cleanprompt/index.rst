CleanPrompt User Guide
======================================================================

CleanPrompt is an edge-native pseudonymization engine for LLM prompts.
It detects personally identifiable information (PII) and sensitive entities in your text,
replaces them with contextually appropriate pseudonyms — entirely on your device —
and restores original values in the LLM's response.
