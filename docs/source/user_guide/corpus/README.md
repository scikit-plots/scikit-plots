# scikitplot.corpus Mermaid RST diagram package

Contents:

- `SCIKITPLOT_CORPUS_USER_GUIDE_MERMAID_DIAGRAM_GUIDELINE.md` — authoring and review rules.
- `corpus_user_guide_schema.rst` — recommended user-guide structure with includes.
- `diagram_include_catalog.rst` — all copy-ready include directives.
- `diagrams/` — one Mermaid diagram per RST fragment.

All diagrams prefer vertical layout. `29_security_and_resource_policy_target.rst`
is explicitly a proposed target architecture and must not be described as current
implementation until the relevant components exist.
