- ``generate_apis_reference coverage`` compares each module's ``__all__``,
  read from the source without importing it, with the API reference, and
  fails on a public name missing from it or a documented name no longer
  public that is not already in ``coverage_baseline.json`` (known gaps,
  which may only shrink). It needs no build and runs as the pre-commit
  hook ``apis-reference-coverage``.
  A ``_name`` in ``__all__`` is reported as a gap of its own (``private``).
  Names a module exports lazily (imported under ``if TYPE_CHECKING:`` with
  a module ``__getattr__``) count as public, and an entry written
  ``"sub.Name"`` documents ``Name``.
  An entry that names a submodule, or a name through one (also through
  ``from .x import *``), is resolved in the source as autosummary resolves
  it, so it is not reported stale. The API reference now lists every
  exception and warning in ``scikitplot.exceptions`` (19 were missing);
  so do the global configuration functions of ``scikitplot.config`` and
  the scikit-learn imputers re-exported by ``scikitplot.impute``; known
  coverage gaps fall from 60 to 20.
