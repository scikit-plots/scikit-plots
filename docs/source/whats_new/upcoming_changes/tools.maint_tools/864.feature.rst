  library and title labeler configurations from the Towncrier owner sections,
  ``scikitplot/_distributions.py`` and one title registry in
  ``pyproject.toml``, and checks all three labeler files against the real
  ``actions/labeler`` v7 and ``github/issue-labeler`` semantics in CI. Every
