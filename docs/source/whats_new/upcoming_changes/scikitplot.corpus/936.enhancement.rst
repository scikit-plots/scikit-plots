- ``OfficeReader`` flags Word text formatted as hidden: a chunk that holds
  any carries ``has_hidden_text=True``, and ``hidden=False`` (which already
  left out hidden slides and sheets) leaves the hidden runs out. Hidden
  text is invisible to a reader but reaches a model that reads the file.
  OpenDocument text counts the same way: conditional hidden text, a
  paragraph marked hidden and a section that is not displayed.
  In Word a character style, a paragraph style or the document default
  that hides text counts as well.
