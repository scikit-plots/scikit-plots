- ``OfficeReader`` now identifies every Office file name. Office add-ins,
  macro sheets and workspaces (``.wll``, ``.wwl``, ``.xll``, ``.xla``,
  ``.xlam``, ``.xlm``, ``.xlw``, ``.ppa``, ``.ppam`` and the Mac variants)
  are refused as code, not documents, instead of failing with "no reader
  registered". Legacy names (``.doc``, ``.dot``, ``.wbk``, ``.xls``,
  ``.xlt``, ``.ppt``, ``.pot``, ``.pps``) are registered: a legacy binary
  file is refused with the reason, and a modern file saved under such a
  name is read.
