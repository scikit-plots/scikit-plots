- ``PDFReader`` takes ``pdfminer_kwargs``, keyword arguments for
  ``pdfminer.high_level.extract_pages``; a mapping under ``"laparams"``
  becomes the layout parameters. pdfminer.six can order the text boxes of a
  page differently on two reads of the same file;
  ``pdfminer_kwargs={"laparams": {"boxes_flow": None}}`` orders them by
  position, which gives the same text every time.
