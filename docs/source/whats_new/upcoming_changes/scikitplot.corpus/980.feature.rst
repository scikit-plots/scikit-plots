- Source code and plain configuration files are read by the new
  ``CodeReader``: about 90 extensions (``.py``, ``.sh``, ``.js``, ``.ts``,
  ``.c``, ``.cpp``, ``.java``, ``.go``, ``.rs``, ``.sql``, ``.tex``,
  ``.ini``, ``.cfg`` and more; ``LANGUAGES`` lists them) are yielded in
  blocks of whole lines, ``lines_per_chunk`` (200) a block, each naming
  its ``language`` and its ``line_start`` and ``line_end``, so a
  retrieved chunk points back to its lines. Indentation is kept.
  ``.env`` is left out because it holds secrets, and extensions two
  languages share (``.m``, ``.pl``, ``.v``, ``.fs``, ``.s``) are left out
  rather than guessed; a subclass adds a language.
