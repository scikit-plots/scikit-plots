- New ``OfficeReader`` reads Word and PowerPoint files in the Office Open XML
  format (``.docx``, ``.docm``, ``.dotx``, ``.dotm``, ``.pptx``, ``.pptm``,
  ``.potx``, ``.potm``, ``.ppsx``, ``.ppsm``) with the standard library only:
  body text and tables in document order, slides in deck order, speaker
  notes, footnotes and endnotes (``notes=``), hidden slides (``hidden_slides=``).
  XML parts are parsed with entity declarations refused, sizes are bounded,
  and macros are flagged (``has_macros``), never run.
