- :meth:`~scikitplot.lean.LeanIndex.discover` counts every load-bearing
  theorem and central concept, not only the ``top`` it lists: the two
  rules said ``count`` = ``top`` and ``cut`` = false however many there
  were (on mathlib4, 50 instead of 113,506 and 37,935). Items are built
  only for what is listed, which makes discovery faster (mathlib4: 1.64 s,
  was 2.02 s).
