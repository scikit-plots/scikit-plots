- :class:`~scikitplot.lean.LeanIndex` gives the same reports whatever the
  order files are added in, as its documentation says: files added out of
  label order are renumbered before the next query, so lists, ties and the
  paths a dossier shows equal :meth:`~scikitplot.lean.LeanIndex.from_folder`'s
  (before, reversed order changed the summary, the shape patterns and the
  headline results). A file without declarations now refreshes the cached
  project-wide results (code that adds declarations, name clashes, imports).
