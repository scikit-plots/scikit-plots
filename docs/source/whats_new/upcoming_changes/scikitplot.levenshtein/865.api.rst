- ``make_corpus_scorer`` is removed: the module no longer imports Corpus.
  Use ``scikitplot.corpus.make_levenshtein_ranker`` (same ordering, cutoff
  and per-hit backend provenance) for ``CustomRetrievalIndex``;
  ``scikitplot.corpus.make_corpus_scorer`` is now the name of the
  scikit-learn compatible *evaluation* scorer.
